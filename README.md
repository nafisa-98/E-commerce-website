# Lime & Tide — E-commerce Website

A modern, responsive e-commerce website built with HTML, CSS, and JavaScript, featuring API-powered products and a custom lime, teal, blue, and orange color palette.

## 🌐 Live Demo

[Visit Lime & Tide](https://nafisa-98.github.io/E-commerce-website/)

## ✨ Features

- Fetch products from the Fake Store API
- Dark and light themes
- Responsive design for all devices
- Product search, filtering, and sorting
- Interactive buying list with quantity controls
- Shopping list persistence using Local Storage
- Loading screen and internet connection error handling
- Google Fonts and Bootstrap Icons

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Fake Store API
- Bootstrap Icons
- Google Fonts
